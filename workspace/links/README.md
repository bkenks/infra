# links/

Index of external resources and where their state lives.

- One file per resource or per provider (e.g. `vultr.md`, `cloudflare.md`).
- Record: what it is, account/console URL, what manages it (Ansible /
  OpenTofu in `../ops/`, Komodo, or nothing), and any caveats.
- Never store credentials here — reference fnox/1Password items instead.
