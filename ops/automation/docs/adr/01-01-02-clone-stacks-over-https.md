# Clone the stacks repo over HTTPS

Supersedes the `github` consequence in `01-01-01-staged-playbooks.md`.

## Context

`50_platform` cloned the stacks repo over SSH. That needed a key on every host, generated by the `git` role and registered on GitHub by the `github` role with a GitHub token that was never configured. The stacks repo is now public at `https://github.com/bkenks/infra.stacks.git`.

## Decision

Clone the stacks repo over HTTPS. Hosts hold no GitHub credentials. The `git` role only installs git, and the `github` role is deleted.

## Consequences

- Hosts can no longer push to GitHub or clone private repos. A future private repo needs its own credential design.
